# Draw.io.ai

Public Codex skill for installing and using the Next AI Draw.io MCP server.

The actual skill lives in:

- [`draw-io-ai/`](./draw-io-ai)

## Install

Ask your AI agent to install this skill by copying the inner `draw-io-ai/` folder into your Codex skills directory:

- Linux / macOS: `~/.codex/skills/draw-io-ai`
- Windows: `%USERPROFILE%\.codex\skills\draw-io-ai`

After installation, restart Codex.

## MCP

This skill is designed for:

- Codex
- Claude Desktop
- Cursor
- VS Code

and other MCP-capable clients using:

- [`@next-ai-drawio/mcp-server`](https://www.npmjs.com/package/@next-ai-drawio/mcp-server)

## Chinese
